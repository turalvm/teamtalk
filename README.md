# TeamTalk 5

Customized TeamTalk 5 client repository for Android and Windows.

## Directory Structure
- `android/`: Android TeamTalk 5 client with MediaTek hardware AEC routing, Headphone routing, Bluetooth support, Quick Move, and accessibility enhancements.
- `windows/`: Windows TeamTalk 5 client with multi-user selection (`Ctrl+Alt+X`, `Ctrl+Alt+M`), clean Turkish, Russian, and English translations, and portable installer script.
